# 📝 QuantX 版本更新记录

本文档记录 QuantX 量化交易系统的版本历史和重要变更，帮助用户了解系统演进和升级指南。

## 📋 版本规范

本项目遵循 [语义化版本控制](https://semver.org/lang/zh-CN/) 规范：

- **主版本号** (MAJOR)：不兼容的 API 修改
- **次版本号** (MINOR)：向下兼容的功能性新增
- **修订版本号** (PATCH)：向下兼容的问题修正

## 🏷️ 版本分类

- 🚀 **新功能** (Feature)：新增功能特性
- 🔧 **改进** (Enhancement)：现有功能改进
- 🐛 **修复** (Bugfix)：错误修复
- 💔 **破坏性变更** (Breaking Change)：不向下兼容的变更
- 🗑️ **废弃** (Deprecated)：计划在未来版本移除的功能
- 🔒 **安全** (Security)：安全相关修复
- 📚 **文档** (Documentation)：文档更新
- ⚡ **性能** (Performance)：性能优化

## 🔄 升级指南

### 从 0.9.x 到 1.0.0

#### 💔 破坏性变更

1. **策略接口变更**
```python
# 旧版本 (0.9.x)
class MyStrategy(BaseStrategy):
    def on_bar(self, bar):
        pass

# 新版本 (1.0.0)
class MyStrategy(BaseStrategy):
    def on_data(self, data: Union[KLine, Tick]) -> None:
        pass
```

2. **配置文件格式变更**
```python
# 旧版本 settings.py
DATABASE_URL = "postgresql://..."

# 新版本 .env
DATABASE_URL=postgresql://user:pass@host:port/db
```

#### 🔧 升级步骤

1. **备份数据**
```bash
pg_dump quantx > backup_$(date +%Y%m%d).sql
```

2. **更新代码**
```bash
git pull origin main
pip install -r requirements.txt
```

3. **运行迁移**
```bash
alembic upgrade head
```

4. **更新配置**
```bash
cp .env.example .env
# 编辑 .env 文件
```

5. **重启服务**
```bash
systemctl restart quantx
```

#### ⚠️ 注意事项

- 策略代码需要更新接口方法名
- 配置文件格式有变化，需要重新配置
- 数据库 schema 有更新，必须运行迁移
- API 接口有新增，客户端可能需要更新

### 兼容性说明

| 组件 | 0.9.x | 1.0.0 | 兼容性 |
|------|-------|-------|--------|
| 策略接口 | ❌ | ✅ | 需要代码更新 |
| 数据库 Schema | ❌ | ✅ | 需要运行迁移 |
| GraphQL API | ❌ | ✅ | 新增功能 |
| REST API | ✅ | ✅ | 向下兼容 |
| 配置文件 | ❌ | ✅ | 需要重新配置 |

## 🤝 贡献指南

### 版本发布流程

1. **功能开发**：在 `develop` 分支开发新功能
2. **测试验证**：运行完整测试套件
3. **文档更新**：更新相关文档和 CHANGELOG
4. **版本标记**：创建版本 tag
5. **发布部署**：部署到生产环境

### 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
feat: 添加新的策略指标计算功能
fix: 修复数据库连接池泄漏问题
docs: 更新 API 文档示例
perf: 优化市场数据查询性能
test: 添加策略回测单元测试
```

### 版本号管理

- 开发版本：`1.1.0-dev`
- 测试版本：`1.1.0-beta.1`
- 候选版本：`1.1.0-rc.1`
- 正式版本：`1.1.0`
