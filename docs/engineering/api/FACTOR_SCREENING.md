# 日级因子选股与历史研究

日级选股以因子条件的交集筛选，不使用信号数量、规则权重或个股预测概率。
盘中量比、首板、涨停和交易执行链路不属于本次重构范围。

## 权威定义与数据

`quantx_domain.factors` 是在线快照、条件校验和离线研究的定义真源。
当前版本为 `daily-v1`，所有输出统一到八位小数后比较，前端仅负责展示格式化。
量比、额比的均值窗口不含当日；60日分位和252日位置包含当日。
窗口不足或分母无效返回空值，不能用短窗口或默认倍数冒充有效值。
在线与离线均按已知市场交易日历保留物理漏行为空值，不能跨过缺失交易日压缩滚动窗口。

RSI采用窗口内涨跌的简单平均；平盘为50，连续下跌可以合法为0。
KDJ的RSV窗口为9，K/D各使用63项2/3指数权重和50初值残差，完整窗口为133根，
交叉判断需134根。固定有限窗口使相同历史截面不受读取起点变化影响。
连续下跌最多观察20个涨跌区间，平盘中断。布林轨附近的条件只表示位置，
不暗示已经发生反弹或突破。

价格特征以截至各行已生效的QMT `dr` 累积复权计算；价格单位字段再换算回
该行未复权价格基准。原始价格保留用于展示。空的公司行为记录不能证明没有公司行为，
必须具有已完成且分片完整的 `qmt-get-divid-factors-v1` 请求覆盖证明。

`indicator_snapshots.calculation_version` 隔离旧计算结果。迁移不会给旧行填新版本；
需通过既有日级快照流程重算。运行元数据的 `signal_version` 内部字段记录同一因子版本，
不再代表选股信号。缺少当前版本的完整运行时，界面明确显示未就绪。
指定部分标的的成功补算记为 `scoped_success`，仍保留运行审计，但不能证明全市场已就绪；
只有实际标的集合与默认股票、ETF全集一致的成功运行才可确认整日完成。
目标日明确停牌或零成交的标的计入 `inactive_target` 并审计跳过，不伪装成计算故障；
其他坏行情、复权或计算错误仍记为失败。历史停牌和缺口继续使受影响滚动窗口不可用。
缺少目标日行情无法被证明是尚未上市或明确停牌，必须使运行降为部分失败，不能证明整日完整。
重算先对本批精确代码、目标日期的旧行撤销当前因子版本资格，再写入计算成功的新行；
即使数据读取或写入失败，也不会继续把已失效的旧值当成本轮结果。旧值保留用于审计，
不删除其他代码或日期的数据。
整日完成资格只看同日、当前因子版本最新创建的运行；新运行尚在执行、失败或仅覆盖
部分股票时，历史成功记录不能继续证明整日完整。结果日期、计算时间始终取实际返回
快照，不能用状态接口中较新的部分运行日期覆盖。

财务、换手率筛选仍可用，但历史财务可见性、质量和流通股本尚未覆盖研究，
不能据此生成精确历史报告。ETF可选股，首版研究仅支持沪深A股。

## 报告与命令

默认最近5年、未来1–20个交易日。两种价格口径分别为
`C(T+h)/C(T)-1` 和 `C(T+h)/O(T+1)-1`。
每个周期独立处理未来数据缺失，不能用第20日的完整性限制第1日样本。
这些是价格关联研究，不是含T+1、涨跌停成交限制、费用和滑点的交易回测。

单因子按每日截面五分位分析，相同值不拆组；二值因子按真假分组。
联合报告仅分析显式条件交集，并比较各单独条件与共同有效股票池基准。
报告同时给出股票日合并统计、日期等权统计、样本数、日期数、年度稳定性及
置信区间。推断使用日期块重采样并校正同次研究的多重比较，不据最高历史胜率
自动选阈值或宣布预测有效。最近一年为稳定性检查，不冒称独立样本外验证。

从仓库根目录执行：

```powershell
uv run --no-sync quantx-research validate --config apps/research/configs/factor_study_smoke.yaml --market-data-archive .runtime/research-source/full-a-share-v2-20200313-20260729
uv run --no-sync quantx-research run --config apps/research/configs/factor_study_smoke.yaml --market-data-archive .runtime/research-source/full-a-share-v2-20200313-20260729
uv run --no-sync quantx-research run --config apps/research/configs/factor_study_v1.yaml --market-data-archive .runtime/research-source/full-a-share-v2-20200313-20260729
```

archive路径是已存在的历史数据源示例，不代表永远最新。运行清单必须展示实际
起止日期、数据指纹、条件和公式版本。小样本配置仅验证工程链路，不是投资证据。
配置也可从选股报告侧栏下载；有不支持的历史条件时，界面给出阻塞原因，不静默删除条件。

报告存于 `.runtime/research-runs/factor-study-v1/`，业务数据库只读。
页面不启动进程、队列、数据同步或交易；报告的定义、条件和数据边界是报告本身的一部分。

## 公共接口与界面

- `stockFactorCatalog`：有限因子目录、公式、单位、版本及研究支持状态。
- `stockScreen`：`factorConditions`、股票池、显式排序和分页；返回因子值及快照版本。
- `stockFactorReportMatches`：批量查找单因子或组合报告，并提供离线配置及命令说明。
- `factorReport`：通过运行key和报告ID读取安全结构化报告。
- `researchRuns` / `researchRun`：研究中心运行索引、详情及其中的因子报告入口。

条件顺序不影响身份；改变阈值或因子版本会重新匹配。匹配与数据质量分别展示。
当前ST、行业或股票子集无法准确还原历史时，只能参考更广股票池的研究，不能标为精确匹配。
不同历史区间保留为独立运行并展示日期，最新成功运行不会覆盖旧报告。

| 页面或浮层 | 内容与数据 | 状态与返回方式 |
| --- | --- | --- |
| `/screening` 日级 | 股票池、因子条件、结果表；目录与筛选查询 | 草稿未应用、加载、空结果、失败、快照未就绪；保留盘中模式 |
| 报告侧栏 | 因子定义、单因子/联合报告、周期曲线与统计 | 匹配、仅参考、缺报告、不支持、样本不足；关闭不丢条件 |
| `/research` | 按研究类型浏览运行 | 分页、加载、失败、空列表 |
| 研究运行详情 | 完整因子报告、周期/收益口径/分组/年度切换 | 产物异常、无报告、完整统计；保留选股页面状态 |

报告针对编辑中的条件，结果表对应最后一次应用的条件，两者不混淆。
默认A股并排除当前ST，无预选因子；按涨跌幅降序、代码升序，支持显式因子排序。
不再以规则分或历史组合胜率为个股打分。

设计采用现有QuantX Studio、公共控件、蓝色交互和红涨绿跌金融语义，支持标准与紧凑密度。
用户已于本次方案确认时明确豁免图片预览，改用实际页面截图和键盘/滚动状态验收；
窄屏报告侧栏使用全宽覆盖层，不改变筛选语义。
