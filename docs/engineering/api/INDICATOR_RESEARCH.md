# 日级指标选股与研究查询

此功能只读已持久化日级快照和离线研究产物；API 不启动研究进程、行情同步或交易。

次日概率候选复用这些指标但具有独立的模型因子、训练、发布和运行契约，见
[`NEXT_DAY_SELECTION.md`](./NEXT_DAY_SELECTION.md)。

## 选股契约

- `stockIndicatorCatalog` 返回唯一权威指标目录：标识、公式说明、单位、历史窗口、计算版本、操作符和研究覆盖状态。
- `stockScreen(input)` 使用 `indicatorConditions`：`indicatorId`、`operator`、`value`、可选 `valueTo`，多个条件全部满足。有限数值零是合法阈值；未知指标、未知操作符、倒置区间直接拒绝。
- 连续指标支持 `gte/lte/gt/lt/eq/between`；二值指标只支持 `eq`，值为 `0/1`。
- 股票池、ST、行业和新鲜度过滤独立保留。默认 A 股、排除当前 ST，不预选财务指标。
- 排序 `sort.field` 为指标标识或 `code/name`，`direction` 为 `ASC/DESC`；默认涨跌幅降序、代码升序。分页在数据库完成，API 不重新评分排序。
- `indicatorValues` 返回所有指标数值，不可计算的值为 `null`。财务指标仍受可见日期与质量门禁限制；其历史研究不因在线可筛选而自动变成已覆盖。
- 页面和结果使用 `calculationVersion`。只读取当前计算版本的快照，旧版信号、权重、规则分及相关日级查询契约已移除。盘中量能和首板接口不变。
- `stockScreenSnapshotStatus.missingSnapshotDates` 从保留窗口内既有快照的最早日期检查到应有交易日；只有当前版本快照与当前版本成功运行的交集算可用。旧版本日期必须补算，不能因为最新一日已重算而漏报；全新数据库没有历史时只要求应有日。此范围仅用于日级指标补算，不限制雷达历史基线。
- 限定标的范围运行成功记为 `scoped_success`，状态和结果明确提示仅完成指定范围；全市场就绪仍只认当前版本的 `success`，不能用一只股票的补算标记整日完成。

## 报告查询与匹配

`stockIndicatorReportMatches(requests)` 一次接受最多 64 个请求，统一扫描运行，不为每个指标重复读取同一产物。每个请求包含唯一 `requestId`、`kind`、`indicatorIds`、`conditions` 和股票池范围。

- `single` 是一个指标的总体分组报告，不接受阈值；指定阈值必须查询 `joint` 条件研究。
- `joint` 的 `indicatorIds` 必须与条件内所有指标一致。规范化操作符和数值后排序、去重，调换条件顺序不改变身份，修改阈值则不匹配。
- `MATCHED` 表示计算版本、条件、股票池、冻结最近 5 年历史区间及默认 1–20 交易日双收益口径匹配，不代表收益可预测或统计显著。历史区间以冻结 `date_range` 的截止日回推 5 个日历年判断（闰日裁剪为 2 月 28 日），不把实际数据覆盖起止误当请求区间。
- `REFERENCE_ONLY` 表示明确披露的更广股票池、限定股票样本、非默认上市时长、不同周期/收益口径，或不同/缺失的冻结历史区间；不能当作当前筛选条件的精确证据。显式 1 年区间即使 `lookback_years` 仍为 5 也只作参考。
- `DATA_INSUFFICIENT` 为条件匹配但样本为空或有效观察日期不足；`MISSING/UNSUPPORTED/ARTIFACT_ERROR` 分别表示缺少报告、研究未覆盖、产物不可用。
- 默认选当前配置下最新成功报告，同时保留历史运行入口和数据起止日期。每个引用返回独立 `matchStatus/matchReason`，切换参考报告时不能沿用整个查询的精确匹配状态。旧计算版本不能借用新指标身份。

响应含结构化配置 `configJson`、分析命令说明 `command`、阻塞原因 `blockers`。配置完整保留当前条件；无法还原历史 ST/行业或未覆盖指标时，客户端必须显示阻塞，不得静默删条件后执行。

`indicatorReport(runKey, reportId)` 返回有界、白名单化的定义、覆盖、分布和类型化统计行。`configJson` 读取真实冻结的 `resolved-config.yaml`，保留研究参数但移除本地输出路径；读取失败为 `null` 并附产物错误。每行明确分组、周期、收益起点、样本量、日期等权统计及上涨比例/平均收益差的置信区间和多重比较校正结果。不是原始 HTML 嵌入，也不是个股预测概率。

`researchRuns(studyId, status, limit, offset)` 在分页之前过滤研究类型。`researchRun(key).indicatorReports` 列出该次运行的报告引用；旧异常放量研究保持原类型与不可变历史输出。

## 产物边界

默认根目录为 `.runtime/research-runs`，可通过 `QUANTX_RESEARCH_RUNS_ROOT` 设置。研究运行 key 为稳定不透明摘要；路径穿越、链接路径、非法 JSON 和非有限数值被拒绝。指标研究指标产物最多 64 MiB、每次运行最多 64 份报告、每份最多 12,000 行；旧研究仍使用原 8 MiB 边界。只列出已结束的运行，不把写入中的文件当成完成报告。

快捷匹配只缓存不含统计行的安全摘要，以已解析路径、修改时间及字节数为键，最多 32 项且总计 8 MiB。每次查询仍先验证路径、链接和文件大小；变更、删除和越界立即失效。冻结配置每次按边界重新读取，配置变更或缺失不会被指标缓存掩盖。完整报告仍按大小边界读取，不缓存原始大 JSON。

修改这些接口后，经 Caddy 公共 `/graphql` 运行 codegen，刷新发布契约，并完成前后端验证；禁止用手工生成类型或 `as any` 绕过契约。
