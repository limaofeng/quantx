## 本轮修复

此前从详情内按钮按 Escape，详情卸载后焦点落到 `BODY`。现在由共享的
`replayEvidenceKeyboard.ts` 在卸载详情前把焦点还给展开行，并尊重已被内部控件处理的
Escape。信号与审计的精确追溯目标均通过行 ref 自动聚焦，不依赖当前已加载的页数。

复盘修复把追溯定位改为按 eventKey 一次性消费：目标首次出现时仍自动展开；只有当前没有
用户已选择的焦点时才自动聚焦。筛选请求暂时清空结果再返回时，不会从搜索框抢走焦点。

分页底部始终保留同一个按钮节点。加载中和末页使用 `aria-disabled` 表达不可操作状态，
点击处理器同时阻止重复请求；末页按钮改为“已全部加载”，不会因原生 `disabled` 或卸载
而把焦点丢到 `BODY`。

回归测试覆盖两页详情内 Escape、信号/上下文目标聚焦、审计关联行自动展开和聚焦、
异步筛选焦点稳定性，以及分页加载中与末页的焦点稳定性。
没有更改 GraphQL 查询、schema、交易语义或中国时区规则。


按用户“先不考虑回放”的范围，本轮不修复该后端/历史数据问题，也不将其标记为通过。
