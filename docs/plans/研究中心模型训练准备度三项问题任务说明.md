# 研究中心训练准备功能完善方案

> 状态：实现与必要验证完成
> 更新：2026-09-07
> 本文替代原“消除三项环境提示”的执行任务。实际样本下载和真实 GPU 资格结果不属于本批完成条件。

## 目标

交付“设置数据范围与来源 → 检查覆盖 → 下载行情或配置历史证据 → 生成并认证数据集 → 返回训练预检”的可操作流程。保存设置、打开页面和查看状态不启动下载、认证或训练。

入口为 `/settings/data/research`，研究中心与数据管理均可进入。历史数据来源沿用 QMT 持久化链路和运行端 CSV/Parquet 文件，不新增供应商。

## 实现约定

- 单账户准备配置保存于 PostgreSQL。任务保存不可变配置快照、阶段、执行标识、检查结果与脱敏错误；重复提交幂等，失败重试复用原请求及已落地下载分块。
- 数据覆盖按股票、基准、交易日历、指标预热、复权覆盖、三类历史证据和次日标签分别说明缺口。当前股票列表不能证明历史全市场完整。
- 下载复用 daily-market-data-sync 及持久化复权请求；仅日线及其依赖，不触发分钟/Tick、实时选股快照、模型推理或交易。
- 认证与 GPU 资格在独立 Research 子进程中运行。认证前固定已校验的历史文件；数据库仅登记通过校验的完整产物。相同版本重跑复用首次创建时间，不同证据拒绝覆盖。
- stock-selection-training-capability 每分钟独立写能力心跳，和长训练、准备任务分离。CPU 来自实际模型烟测，180 秒门禁不放宽；探测失败不刷新旧证据。
- GPU wheel 绑定实际安装二进制；环境哈希包含二进制、设备、驱动及 OpenCL 信息。Windows 安装由运维执行，页面仅提供资格任务与状态；无认证数据集时等待，不伪造资格。
- 所有准备任务保留 full/live 交易关键时段排队边界，后台调度不会因页面打开而创建任务。

## 部署与接口

新增 GraphQL：researchPreparation、previewResearchDownload、saveResearchPreparation、startResearchPreparation、retryResearchPreparation。复用既有训练能力、认证数据集和训练预检接口。

新增数据库迁移 `20260907_0057`，新增两张表。Worker 部署定义继续由统一 Windows 入口管理。

现场验证发现 Prefect 客户端 3.7.8 与 Server 3.6.15 的新建部署协议不一致，Worker 现锁定 3.6.15，并显式安装该版本 CLI 所需的 importlib-metadata；没有引入协议兼容分支。

详细使用说明：[研究训练数据准备](../../apps/docs/content/guide/research-preparation.md)。

## 验收与边界

- 专用测试库、小样本及模拟 Agent/Prefect 验证设置持久化、下载预览与重试、历史文件校验、认证幂等、心跳独立性、GPU 环境变化失效。
- 前端验证空数据集可进入准备页、未保存配置禁止提交、预览不启动下载、GPU 不合格不单独阻止 CPU。
